# Flutter reference harness

The local `ios_sheet_engine` fork, opaque `simple_stupid_ios_sheet` wrapper,
research harness, and interactive API playground live here. iOS 26 is the only
supported native reference; the default profile remains unmeasured.

Start with the [wrapper package journey](packages/ios_sheet/README.md) and
[minimal public example](packages/ios_sheet/example/lib/main.dart). Source and
license boundaries are in [fork provenance](../docs/FORK_PROVENANCE.md).
